# UVS 2 ECO CLUB

Сургуулийн экологийн клубын GitHub Pages веб сайт.

## Файлын бүтэц

- `index.html` — нүүр хуудас
- `pages/` — тусдаа хуудсууд
- `css/style.css` — ерөнхий дизайн, өнгө, картууд
- `css/header.css` — дээд хэсэг, навигацийн цэс
- `css/footer.css` — хөл хэсэг
- `js/menu.js` — гар утасны цэс, дэд цэс
- `js/main.js` — нийтлэг JavaScript
- `js/news.js` — мэдээний үйлдэл хийхэд бэлэн файл
- `data/news.json` — мэдээний жишээ өгөгдөл
- `data/projects.json` — төслийн жишээ өгөгдөл
- `assets/images/` — өөрийн лого, зураг

## GitHub Pages

Repository-ийн **Settings → Pages → Deploy from a branch → main → /(root) → Save** гэж тохируулна.

## Анхаарах зүйл

Одоогийн мэдээ болон төслүүд нь жишээ агуулгатай. Бодит мэдээллээр солиорой. GitHub Pages нь статик сайт тул админ нэвтрэлт, сервер талын өгөгдлийн сан зэрэг боломжид тусдаа backend эсвэл CMS хэрэгтэй.
